# Herkunft der Skills in diesem Ordner

Die Unterordner stammen aus https://github.com/emilkowalski/skills
(Emil Kowalski – Sonner, Vaul, animations.dev), Stand: siehe Commit-Datum.

Übernommen wurden die Skills, die für eine Website im Browser gelten.
Nicht übernommen: `write-swift` und `animate-expo` – beide gelten für
native Apps und hätten hier nur die Liste verlängert.

Aktualisieren: Ordner aus dem Repo erneut kopieren, oder auf dem eigenen
Rechner `npx skills@latest add emilkowalski/skills`.

Es ist reiner Text: Anleitungen, Tabellen mit Kurven und Dauern,
Beispielcode. Keine Skripte, keine Netzaufrufe.
